# Todo List

A simple Todo List web application that allows users to create, edit, complete, and delete tasks. React Todo list applicacation,that allows users to add.  
 The project was built as a learning exercise to practice working with React JS

## Installation

To set up the project on your local machine, follow these steps:

1. **Create a New Local Folder:**
   `mkdir my-todo-app`
2. **Open new folder**
   `cd my-todo-app`
3. **Make clone project**
   `https://github.com/Elmira2505/react_todo_list.git`
4. **Install the dependencies to the local node_modules folder.**
   `npm install`

## How to run the development server

1. **Start the Development Server:**
   `npm run dev`
2. **Open in Browser:**
   Navigate to http://localhost:5173 to see the app in action.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
